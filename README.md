# Hisaab
Nothing just needed an app my way.....

Hisaab is a small personal money tracker for Android. You keep several accounts (a bank, a mobile wallet, cash), record money coming in and going out, and see the balance of each account and the total across all of them. Amounts are stored as whole paisa, so there are no rounding errors.

## Features

- Multiple accounts, each with its own balance
- Total across all accounts on the home screen
- Ingoing entries with a source (Salary, Allowance, Mamu's money, or your own)
- Outgoing entries with an optional note
- Edit and delete entries
- Backup export and import as a JSON file

All data stays on your phone. No internet, no account, no server.
